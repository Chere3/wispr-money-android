# Seguridad

Si encuentras una vulnerabilidad (por ejemplo, una forma de extraer el token guardado o de que la
app filtre datos financieros), **no abras un issue público**. Repórtala en privado desde
[Security → Report a vulnerability](https://github.com/Chere3/wispr-money-android/security/advisories/new).

No incluyas datos financieros reales en el reporte.
